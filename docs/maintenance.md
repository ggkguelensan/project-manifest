# Сопровождение

Перед добавлением найди владельца смысла и потребителей, устрани дубли и конфликты, сохрани условия и исключения. AGENTS маршрутизирует, docs определяют нормы, skills описывают действия, schema определяет поля. README объясняет использование человеку.

Проверки: `npm run check`, `npm test`, `git diff --check`. Tests используют отдельные Git fixtures внутри игнорируемого `e2e/tmp/`; не трогают реальные проекты. Не создавай tests на точное совпадение формулировок.

Версия пакета, версия project schema и закреплённые commits независимы. Неизвестная schema отклоняется. История живёт в Git; пользовательская адаптация сохраняется при обновлении, не преобразуется молча. Разработка допускает task-ветки, использование — закреплённые commits и detached HEAD. Публикация и CI/CD требуют поручения.
