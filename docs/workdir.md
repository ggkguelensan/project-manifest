# Сохранение локальной адаптации

Читай перед обновлением базы или переносом локальной адаптации. workdir не является кешем: checkout/setup сохраняют его. Git commit закрепляет базу, но не сохраняет игнорируемые проектные данные.

Каждый предметный манифест владеет своим форматом адаптации. Project Manifest предоставляет необязательную файловую операцию резервного копирования для любого из них — без копирования схем, миграции, registry или публикации.

Из checkout Project Manifest:

```sh
npm run workdir -- export --base /absolute/e2e-manifest --selection project/web --target /absolute/worktree/apps/web --name before-update
npm run workdir -- restore --base /absolute/e2e-manifest --selection project/restored-web --target /absolute/worktree/apps/web --name before-update
```

selection — каталог относительно workdir выбранной базы. Результат экспорта находится в `<target>/e2e/tmp/exports/<name>/`: data содержит исходные bytes и пустые каталоги, backup.json — inventory SHA-256, исходную selection и commit базы. Это резервная копия, не активная адаптация и не альтернативный нормативный реестр.

Операции локальны, не вызывают fetch/checkout и не запускаются hooks автоматически. Экспорт не удаляет источник. Restore допускается только в новый каталог workdir: существующие файлы и даже dangling symlink не заменяются. Перед записью проверяются версия inventory, пути, состав файлов и hashes. Symlinks и специальные файлы не экспортируются; код из адаптации не выполняется. Не запускай параллельное изменение выбранных каталогов во время копирования.

После restore запусти валидатор владельца формата. Несовпадение base_revision, истёкшее review или изменившиеся относительные ссылки требуют явного решения; restore не переписывает их ради успешной проверки. Исходная адаптация остаётся доступной, пока пользователь не решит заменить или удалить её.

Не включай credentials и реальные персональные данные в workdir. Backup не является secret scanner. Экспорт в e2e/tmp не означает разрешение отправить его наружу. Перед очисткой tmp отдельно сохрани нужную резервную копию в согласованное место; наличие backup в том же рабочем дереве не защищает от удаления всего worktree.

Для самостоятельного использования E2E/Design без Project Manifest допустима обычная локальная копия выбранного workdir в новый каталог, с проверкой состава и hashes и последующей валидацией владельца. Инструмент Project Manifest не является обязательной runtime-зависимостью этих баз.
